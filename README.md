# tee-up

Present one fully prepared decision at a time, with the situation, practical consequences, tradeoff, and an honest lean.

## Use

> Tee up the unresolved decisions one at a time, starting with the easy ones.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `tee-up/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
